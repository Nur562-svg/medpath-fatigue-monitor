# MedPath · 驾驶员疲劳实时监测原型

> 2026 江苏“创青春”AI+交通创新创业大赛 · 自由创新开放赛道 · 创新组

## 项目简介

本原型聚焦 **AI + 交通安全**，基于 MediaPipe 计算机视觉技术，实时提取驾驶员眼部、嘴部、头部姿态关键点，结合规则引擎与轻量时序分析，实现疲劳风险分级评估，并融合中西医临床知识给出应急与健康建议。

**核心特点：**
- 纯前端轻量化部署，打开网页即可使用
- 实时检测眨眼（EAR）、打哈欠（MAR）、头部俯仰
- 疲劳等级：正常 / 轻度 / 中度 / 重度
- 以现代医学应急处理为主，辅以简单中医穴位建议
- 适合高速公路、网约车、物流运输等场景演示

## 快速体验

1. 使用 **Chrome** 浏览器打开 [在线演示](https://nur562-svg.github.io/medpath-fatigue-monitor/)（部署后可用）
2. 点击「开始监测」，允许摄像头权限
3. 正面面对摄像头，系统将实时显示疲劳状态与建议

> 本地运行：直接用浏览器打开 `index.html` 即可（需联网加载 MediaPipe 模型）。

## 技术栈

- MediaPipe Face Landmarker（官方 Tasks Vision）
- 纯 HTML / CSS / JavaScript（无框架、无后端）
- 实时指标：EAR、MAR、头部俯仰角 + 时序平滑
